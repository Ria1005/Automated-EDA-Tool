The full pipeline

The demo above runs the cleaning and profiling steps live. In the downloadable Python version, those same steps sit inside a six-stage pipeline that also puts your data in a real SQL database.

1

Collect

Read the raw file — CSV, Excel, JSON, or Parquet.

2

Load into SQL

Written into a SQLite table as the source of truth.

3

Clean with pandas

Fix dtypes, fill missing values, drop duplicates, cap outliers.

4

Write back to SQL

Cleaned table saved alongside the raw one, queryable either way.

5

Profile

Summary stats, distributions, and correlations.

6

Report

One standardized HTML report, every dataset, every time.
